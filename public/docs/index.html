Introduction

API de LawLens Morocco — accompagnement juridique des entrepreneurs au Maroc (Sanctum).

Base URL: http://localhost:8000 
Cette documentation couvre l'ensemble des endpoints de l'API **LawLens Morocco** :
gestion des projets, génération de roadmaps d'accompagnement, catalogue juridique
(structures et règles) et administration.

<aside>As you scroll, you'll see code examples for working with the API in
different programming languages in the dark area to the right (or as part of the
content on mobile). You can switch the language used with the tabs at the top right
(or from the nav menu at the top left on mobile).</aside>

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {YOUR_SANCTUM_TOKEN}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

Récupérez un jeton en vous authentifiant via POST /api/login (ou POST /api/register), puis envoyez-le dans l'en-tête Authorization: Bearer <token>.
